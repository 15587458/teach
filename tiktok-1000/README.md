# TikTok: «Как заработать первые $1000»

Готовое видео: `out/first_1000.mp4` (1080×1920, 30 fps, ~68 сек, русская озвучка).

**Герои:** Макс (у него на карте 3$) и Лиза (подруга, которая знает, как надо), плюс голос за кадром.

**Сюжет:**
1. Крючок: «На карте... 3$. А мне нужна ТЫСЯЧА!» — Макс падает в кадр, Лиза влетает сбоку.
2. Шаг 1 — продай навык: монтаж роликов для кафе → +200$.
3. Шаг 2 — продай ненужное: приставка, наушники, куртка → +150$.
4. Шаг 3 — деньги рядом: репетиторство, помощь соседям → +240$.
5. Поворот: «Иду за кроссовками!» → «СТОП!» (скретч пластинки, тряска камеры) → вложение в микрофон → +420$.
6. Финал: $1013, конфетти, фанфары, «Ты сделал систему», призыв написать в комментариях.

## Пересборка
```bash
sudo apt-get install -y rhvoice rhvoice-russian ffmpeg
pip install pillow numpy
python3 voices.py   # озвучка (RHVoice: aleksandr-hq / artemiy / anna)
python3 render.py   # видео + музыка + эффекты -> out/first_1000.mp4
python3 render.py --preview 5,20,44   # отдельные кадры в build/preview/
```
Текст и реплики меняются в `script.py`, персонажи — в `chars.py`.
